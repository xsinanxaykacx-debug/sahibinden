# Sahibinden Ürün Fotoğrafları

Bu depo, ürün listesindeki otomotiv aydınlatma parçaları için doğrulanmış görselleri ürün bazında düzenlemek amacıyla hazırlanıyor.

## Eşleştirme kuralları
- Öncelik: OEM/parça numarası ve üretici kodu.
- Sol/sağ taraf ayrı tutulur; yön uyuşmuyorsa görsel eşleşmiş sayılmaz.
- Aynı parça numarasının tekrarları tek görsel klasörüne bağlanabilir; liste satırları katalogda ayrı korunur.
- OEM kodu bulunmayan ürünlerde barkod ve etiket kodu aranır.
- Eşleşme kesin değilse tahminî görsel kullanılmaz; `INCELEME_GEREKLI` olarak işaretlenir.
- Ürün satırları `katalog.csv` dosyasında izlenir.

## Durum
İlk doğrulanan örnek eşleşmeler:
- `6208K6`: sol far, Peugeot/Citroën referansı.
- `260100506R`: sağ ön far, Renault Megane IV.
- `260601571R`: sol ön far, Renault Megane IV.

Görsel dosyaları eklendikçe ürün klasörleri ve kaynak bilgileri bu depoda güncellenecektir.
